# Changelog

## 1.0.0 (2026-10-21)

First complete release of the course.

- **8 modules, 105 labs**: ML foundations; data preparation and feature engineering; regression; classification and evaluation; trees, ensembles, tuning and explainable AI; unsupervised learning, recommendations and embeddings; neural networks and a TinyGPT; GenAI, RAG and AI agents.
- **7 assignments** (Modules 2-8), each with a solved worked example, a starter and an automated 40-point rubric.
- Each module comes with a reusable toolkit, synthetic data with a known ground truth, cached real datasets, and a README with the episode plan and key numbers.
- Repository: README, syllabus, MIT license, contributing guide, code of conduct, security policy, citation file, pinned test versions (`constraints.txt`), a GitHub Codespaces dev container, and `run_all.py` for the whole course.
